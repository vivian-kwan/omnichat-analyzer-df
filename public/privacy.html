Omnichat Analyzer

Privacy Policy

Last updated: 2026-09-08

What this extension is

Omnichat Analyzer is a Chrome extension built by DF創意家居 for its own pre-sales customer service team. It runs only on console.omnichat.ai, DF's live-chat platform, and helps sales reps analyze the conversation currently open in that console: summarizing it, detecting the quoted price, classifying it into a sales-funnel stage, and applying the matching tag. It is not distributed to, or intended for, the general public.

What data this extension reads

When a rep runs an analysis, the extension reads:

  • The customer conversation currently open (or a batch of conversations, for bulk analysis) inside the Omnichat console — message text, sender, and timestamps.
  • The rep's own account details entered into the extension's Settings tab: their login token and the API key for whichever AI provider they've chosen (OpenAI, Google Gemini, or DeepSeek).

It does not read any other website, and does not read your general browsing/web history.

Where that data goes

Conversation content is sent to two places, both necessary to produce the analysis the rep asked for:

  • DF's own backend server (api.df-creativehome.com), which authenticates the rep and relays the request to the AI provider. The server does not persist raw conversation text to disk — it is processed in memory for the duration of that one request and then discarded.
  • The AI provider the rep selected (OpenAI, Google Gemini, or DeepSeek), using the rep's own API key, to generate the summary/classification. Each provider's own privacy policy governs how they handle a request sent to their API.

DF's backend separately stores account/config data needed for the team to use the tool at all: login tokens and roles for each rep, and a small shared library of AI prompt templates, saved reply templates, and common-question shortcuts the team has chosen to save. It does not store a running archive of customers' raw chat transcripts.

What's stored on your own device

The extension saves your own settings in Chrome's local/sync storage (never sent to us until you use a feature that needs it): your login token, your chosen AI provider and its API key, and small UI preferences like whether the panel is collapsed. This is what lets you avoid re-entering your token/key every time you open the tool.

What we don't do

  • We do not sell or rent any data to third parties.
  • We do not use conversation content for advertising, and there is no ad or analytics SDK in this extension.
  • We do not use this data to determine creditworthiness or for lending purposes.
  • We do not transfer data for any purpose unrelated to the analysis feature described above.
This extension is built for one company's internal sales team. If you were given a link to install it and you are not part of that team, it will not function for you — every request requires a login token issued by a DF admin.
